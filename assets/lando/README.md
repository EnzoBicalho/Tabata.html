# Hero reference assets

Portrait, depth, alpha, normals, shadow texture, helmet geometry, material textures and studio lighting from the initial hero at https://landonorris.com/, incorporated at the user's explicit request.

Original asset host: https://lando.itsoffbrand.io/gl/ . Geometry was extracted from the reference browser's decoded helmet scene and packed into `subjects.bin`; `subjects.json` describes its typed arrays. No reference site bundle is used by the portfolio.

Replace the square portrait/alpha/depth/normal textures or the helmet parts independently through `hero-subjects.js`. These assets remain reference material and do not represent portfolio projects.

The active hero now uses the user-provided portrait in `assets/enzo/`. These reference assets remain available on disk but are no longer requested by the hero.
